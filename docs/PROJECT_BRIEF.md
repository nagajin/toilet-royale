# Toilet Royale / トイレロワイヤル

## Concept

『トイレロワイヤル』は、巨大トイレのあるステージでプレイヤー同士が押し合い、
水流に流されずに最後まで残ることを目指す物理パーティアクションゲームである。

## Core Hook

「流すか、流されるか。」

## Target

- 15秒動画で面白さが伝わる
- 配信者が友達と遊んで盛り上がる
- 低価格Steamゲームとして成立する
- 最初はローカル対戦を優先し、オンライン対戦は後回しにする

## First Prototype Goal

Version 0.1では、次だけを実装する。

- 1ステージ
- 1〜4人の簡易プレイヤー
- 中央の巨大トイレ
- 一定時間ごとの水流イベント
- 吸い込まれたら脱落
- 15秒動画として笑える挙動
