# Toilet Royale / トイレロワイヤル

「街を汚せ，敵を流せ！」

街を舞台にした3Dチームアクション．うんこを投げて敵便器へ流し込む得点行動と，
道を汚して滑らせる妨害，ブラシ清掃，食堂補給を組み合わせる．敵本人も便器の水流で流せる．

## ユーザーの構想（2026-09-07に確認）

1. 敵のトイレにうんこを流すと1ポイント．
2. 敵陣を投擲で汚し，滑る領域を作る．トイレブラシで清掃できる．
3. 自陣の食堂で食事をして補給する．
4. FPSや肩越しの三人称のように，キャラクターに近い視点で操作する．
5. 街の世界観で，チームごとに便器を2か所ほど自動生成する．
6. 敵プレイヤー本人も流せる（追加質問への回答で確認）．

v0.3のボール競技はこの構想と異なっていた．過去の試作として保存し，本線は街モードへ置き換え，v0.5で表現を更新した．

## 現在の実装

自分＋味方CPU 対 敵CPU2体で動作を試せる．仮の試合時間は3分間．
肩越しの三人称を標準に，一人称へ切り替え可能．街の配置はシードで再生成できる．

表現の指定は「ゲームらしさを保ち，街・質感・動きをリアルにする」．商店街の細部・素材・光・キャラクター動作と効果音をv0.5に実装した．
