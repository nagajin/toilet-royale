# Game Design

## Core Rule

プレイヤーはステージ上で移動し、中央または端にあるトイレの水流に吸い込まれないように戦う。

## Win Condition

最後まで流されずに残ったプレイヤーが勝利する。

## Prototype v0.1

### Player

- 移動できる
- ジャンプまたはダッシュできる
- 水流の影響を受ける
- ステージ外または便器内に落ちると脱落する

### Toilet

- 一定時間ごとに水流を発生させる
- 水流中はプレイヤーを吸い込む
- 水流前に警告演出を出す

### Stage

- 1画面の固定ステージ
- 中央に巨大トイレ
- 左右に安全地帯
- 最初は仮素材でよい

## Do Not Implement Yet

- オンライン対戦
- Steam実績
- 課金
- 複数ステージ
- 複雑なキャラ育成
- 高品質な3Dモデル
