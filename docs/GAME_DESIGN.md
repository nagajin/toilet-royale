# Game Design

## 遊びの流れ

自陣の食堂で食べる → 街へ出る → 敵便器を狙って投げる → 得点，または着弾地点が汚れる → 清掃・防衛・再補給．

プレイヤーはオレンジチーム．敵はミントチーム．各チームに便器2基と食堂1か所を用意する．
街には中央通り，横道，建物の区画があり，便器は塞がれていない広場へ対称配置で生成する．

## 得点と妨害

敵の便器の水面へうんこが落ちると1ポイント．自陣の便器へ入れても得点しない．
投擲が地面に着弾すると汚れが残る．汚れは両チームとも滑る．汚れ面積は得点ではなく状況表示に使う．
投擲が敵に当たると押し戻す．ブラシでも近くの敵を押し出せる．

## 補給と清掃

投擲の所持上限は6個．自陣の食堂付近でEを1.5秒長押しして食事すると満タンになる．
食事をやめる・食堂から離れると途中の進捗は失う．敵陣の食堂では補給できない．
Qを押している間，周辺2.5mの汚れを清掃する．清掃で弾薬は消費しない．

## 敵本人を流す

自陣の便器から4.8m以内でFを押すと水流を作動させる．
便器から6m以内で壁に遮られていない敵を吸い込み，3秒後に敵の自陣へ復帰させる．
味方は流さず，復帰直後には2秒間の保護を付ける．水流の再使用待ちは7秒．
敵を流す行為に追加得点は付けず，攻撃の中断と防衛に使う．

## 視点と試合

肩越しの三人称でマウス照準を操作．右クリックで寄って予測軌道を見る．Vで一人称へ切り替える．
壁に近づくとカメラの距離を縮める．近すぎる看板は非表示にして視界を保つ．

現在は自分＋味方CPU 対 敵CPU2体．仮の試合時間は3分で，得点の多い側が勝利，同点は引き分け．
CPUは道路を通って敵便器へ進み，投擲・食堂への帰還・補給・清掃・水流を行う．

## 表現の方向（v0.5）

ユーザー指定は「ゲームらしさを保ち，街・質感・動きをリアルにする」．
チーム色と大きな便器は識別しやすく保つ．生活感のある商店街，陶器・舗装・水の質感，肘・膝を使う動きと手元を加える．
視点の揺れは控えめにし，得点・清掃・補給の判定から演出を分離する．効果音はEscメニューから消音できる．

## 次の調整

対人の操作方式，投擲速度・滑り・水流範囲，CPUの役割分担，街の多様性をプレイ評価で調整する．
街モードの対人・オンライン・パッド操作とBGMは未実装．モデルは手続き生成で，専用のスキニングモデルやモーション素材はまだ使用していない．
