# Development Log

## 2026-07-06 — v0.1 Flush Prototype

### 目的

「巨大トイレの水流に吸い込まれるだけで面白いか」を検証する最小プロトタイプの実装。

### 技術選定

- HTML5 Canvas + 素の JavaScript（依存ゼロ、ビルド不要）
- 理由: 開発環境に Godot が未インストールで実行確認できないため。
  ブラウザで開くだけで動き、ロジックを Node.js でテストできる。
  核が面白いと確認できたら Godot 4 への移植を検討する。

### 実装内容

- `prototype/sim.js` — 物理・水流状態機械（idle 5s → warning 2.5s → flushing 3s のループ）。
  吸引はトイレへの距離で強くなる加速度。地上より空中のほうが強く流される。
  プレイヤーは配列＋スポーン地点4つで、ローカル2〜4人対戦に拡張可能な構造。
- `prototype/game.js` — Canvas 描画（巨大トイレ、渦、風パーティクル、画面振動、
  警告演出「ゴゴゴゴ…」、螺旋吸い込み演出、パニック顔）、キー入力、イベントログ。
- `prototype/index.html` — エントリポイント。
- `prototype/test_sim.js` — Node で動く簡易テスト（25件、全て成功）。
- `specs/v0_1_flush_prototype.md` — 実装スペック。
- `README.md` — 実行方法。

### バランス（テストで担保）

- 中央寄り（x=300）で無入力 → 1回の水流で流される
- 画面端で無入力 → 生き残れる（左右が安全地帯）
- 逃げ方向に入力し続ければ抵抗できる（操作不能ではない）

### Codexレビュー（実施済み）

- Must fix 1件: 脱落判定 `deathY: 500` が水面 `waterY: 524` より上で発火し、
  仕様「水面より下に到達で脱落」とずれる → `deathY: 526` に修正済み（テスト全件成功を再確認）
- Can wait として指摘（v0.2以降で対応）:
  - `game.js` が単一プレイヤー固定（`createWorld(1)`、`KEYMAPS[0]`、UIが `players[0]` 前提）
  - 吸引方向がトイレ中心ぴったりで右向きになる（中心で0が直感的）
  - 当たり判定が中心点のみ（便器のフチで半分はみ出て立てる）
  - R キーのキーリピートでリセットログが連発する
  - 極端に大きい dt でフェーズ遷移が1回分しか処理されない（描画側で dt を 1/30 に制限済みのため実害小）
- スコープ外の実装・不要な大規模変更なしと確認された
