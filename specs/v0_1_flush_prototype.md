# Spec: v0.1 Flush Prototype

## 目的

「巨大トイレの水流に吸い込まれるだけで面白いか」を検証する最小プロトタイプ。
完成度ではなく、15秒動画で伝わる挙動の検証が目的。

## 技術選定

- HTML5 Canvas + 素の JavaScript（依存ライブラリなし、ビルド不要）
- 理由:
  - この開発環境に Godot が未インストールで、実行確認・自動テストができない
  - ブラウザで `index.html` を開くだけで動作確認できる
  - ロジック（`sim.js`）と描画（`game.js`)を分離し、Node.js で物理挙動をテストできる
  - 核が面白いと確認できたら Godot 4 等への移植は容易な規模に留める

## 画面構成（横スクロールなしの1画面・横視点）

```
+------------------------------------------------+
|  UI: 水流までの残り時間 / 流された回数            |
|                                                |
|                  [タンク]                       |
|                  |ゴゴゴ|   ← 警告演出           |
|  ______________ (  bowl  ) ______________      |
|  左の安全地帯    \ 水流渦 /     右の安全地帯      |
+------------------------------------------------+
```

- ステージ: 960x540 の固定1画面
- 中央: 巨大トイレ。床に便器の開口部（穴）があり、落ちると脱落
- 左右: 床（安全地帯）。画面端に壁

## プレイヤー

- 1体（ただし内部は配列＋キーマップ表で、2〜4人ローカル対戦へ拡張可能な構造にする）
- 操作: ←→ / A D で左右移動、Space / W / ↑ でジャンプ
- 物理: 重力、目標速度への補間（地上は速く、空中は遅く効く）
- 空中では水流の影響を強く受ける（ジャンプ＝リスク、というコメディ要素）

## 水流イベント（状態機械）

| フェーズ | 時間 | 内容 |
|---|---|---|
| idle | 5.0s | 通常。カウントダウン表示 |
| warning | 2.5s | タンクが震える・「ゴゴゴゴ…」・画面微振動 |
| flushing | 3.0s | プレイヤーをトイレ中心方向へ吸引。渦・風エフェクト・画面振動 |

- 吸引力: トイレに近いほど強い（距離による係数）。地上で入力なしだと
  中央付近では逃げ切れず、画面端なら耐えられるバランス
- 吸引は加速度として与え、移動入力で抵抗できる（操作不能にはしない）

## 脱落とリスタート

- 便器の開口部に落ちる（水面より下に到達）と脱落
- 脱落演出: 渦の中心へ螺旋を描いて縮みながら吸い込まれる（約0.9s）
- その後 1.2s で左端の安全地帯にリスパウン（検証を回しやすくするため自動復帰）
- 「流された回数」をUIに表示、イベントログにも記録

## UI / ログ

- 上部: フェーズ表示（水流まで N.Ns / まもなく水流！ / 水流中！！）、水流回数、流された回数
- 画面下: 直近のイベントログ（水流開始、脱落など）
- R キーでカウンタリセット

## 実装しないもの

- オンライン、Steam、課金、複数ステージ、キャラ選択、高品質アセット、
  セーブ、実績、ランキング、タイトル画面、BGM/SE（docs/GAME_DESIGN.md 準拠）

## ファイル構成

- `prototype/index.html` … エントリ。ブラウザで開くだけで動く
- `prototype/sim.js` … 物理・状態機械（純ロジック、Node でも動く）
- `prototype/game.js` … 描画・入力・エフェクト（ブラウザ専用)
- `prototype/test_sim.js` … Node で動く簡易テスト
