# Spec: v0.3 Local Toilet Match

> 過去の試作．ユーザーの構想との相違が確認されたため，本線は [v0.4](v0_4_city_battle.md) に訂正．

## 今回の到達点

便器ゴールの試作を，人数選択から勝敗・再試合まで遊べるローカル対戦にする．
v0.2.5 のフィールド・ボール・便器・水流演出を継続し，v0.2 水流検証シーンは保存する．

## ルール

- 1人：時間・勝利点の制限なしの練習．得点とゴール後のキックオフは対戦と共通．
- 2人：P1（あか）対 P2（あお）．
- 3人：P1・P3（あか）対 P2（あお）．人数差のある2対1として明示する．
- 4人：P1・P3（あか）対 P2・P4（あお）．
- 左のあか便器はあかの自陣，右のあお便器はあおの自陣．**相手色の便器に入れると得点**．
- 90秒または5点先取で終了．時間切れ時に同点なら引き分け．
- 3秒のキックオフ → 試合 → 1.8秒のゴール演出 → 全員とボールを戻して3秒のキックオフ．
- 試合時計はプレイ中だけ進む．ゴール演出・キックオフ・一時停止中は進まない．
- ゴール演出中，キックオフ中，試合終了後は移動と追加得点を受け付けない．
- 場外球は得点を変えず全員を戻して再開．プレイヤー単独の場外落下は個別に復帰．

## 操作

| プレイヤー | 移動 | ジャンプ | チーム |
|---|---|---|---|
| P1 | WASD | Space | あか |
| P2 | 矢印 | Enter | あお |
| P3 | IJKL | U | あか |
| P4 | TFGH | Y | あお |

- Esc / パッドの Start：一時停止・再開．R：現在の人数で再試合．
- 各プレイヤーは接続順のパッド1〜4でも操作可能（左スティック＋下側ボタン A / ×）．
- パッドの接続変更時は割り当てを更新し，試合中なら一時停止．フォーカスを失った場合も一時停止．
- キーボードとパッドは併用可．キーボードの同時押し上限は機種依存．パッド実機による確認は未実施．
- ロビーはマウスまたは矢印・Tab・Enterで操作可能．

## 実装

- `local_match.gd`：シーンに依存しない得点・時計・勝敗・フェーズ．
- `local_controls.gd`：`local_p1_*`〜`local_p4_*` の独立した入力．旧版の `p1_*` は保持．
- `goal_player.gd`：走行速度と外部から押された速度を分離．接触相手に押し出し速度，自分に反動を与える．ボールへの押力は入力方向に応じて適用．
- `toilet_goal.gd`：ボールがフィールド側から便器の入口平面を越えたことを確認．背後・側面・上からの侵入は無得点．
- `ball.gd`：得点後の吸い込み演出，速度上限，連続衝突判定，最新のロック状態に従うリセット．
- `toilet_goal_game.gd`：スポーン・画面・演出を接続する統括．遅延タイマーを持たず，フェーズで進行する．
- `match_hud.gd`：人数選択，チーム得点，時計，キックオフ，ゴール，一時停止，結果と再試合．
- カメラは左右の便器の開口部が見える透視投影．1280×720 / 960×540で確認．

## 検証方法

```bash
./run-game.command --headless --script res://tests/test_match.gd --fixed-fps 60
./run-game.command --script res://tests/capture_match.gd --fixed-fps 60
```

起動ファイルがクラス登録を自動インポートする．最後のコマンドは通常描画を使い，画面PNGを `/tmp/toilet-royale-*.png` に保存して終了する．
ルールだけでなく実シーンの物理演算で，左右のゴール，両方向の押し合い，ジャンプ，リセットを検証する．
