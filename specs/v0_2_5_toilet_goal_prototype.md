# Spec: v0.2.5 Toilet Goal Prototype

> 本文はv0.2.5時点の記録．現在の本線は [v0.3](v0_3_local_match.md) へ進んでいます．

## 方針転換の理由

これまでの v0.2 は「巨大トイレの便器内でプレイヤーが水流から逃げる」ゲームだったが、
企画の本来の方向性を以下に修正する。

**Fall Guys 的なわちゃわちゃ感を持つ、便器ゴール型の3D物理パーティ競技ゲーム**

- サッカーや押し込み競技の分かりやすさ（ルール説明が要らない）
- ゴールが巨大便器＝見た瞬間に面白い構図
- ゴール時に水流で流れる＝爽快感と笑い
- うんこ・ブラシ・トイレットペーパー等のトイレ系アイテムで妨害とカオスを足せる
- 「便器内で逃げる」より対戦の絵が作りやすく、15秒動画映えする

v0.2.5 の検証課題: **「サッカーのゴールが便器になっている構図が、見た瞬間に面白いか」**

## v0.2 と v0.2.5 の違い

| | v0.2（技術検証として保存） | v0.2.5（本線） |
|---|---|---|
| 舞台 | 巨大トイレの上（便座リング） | 長方形フィールド |
| 目的 | 水流から逃げて生き残る | ボールを押して便器ゴールに流し込む |
| トイレ | ステージそのもの | 左右のゴール |
| 水流 | 定期イベント（脅威） | ゴール演出（報酬） |
| シーン | `scenes/main.tscn` | `scenes/toilet_goal_prototype.tscn` |

v0.2 は削除しない。水流ギミック・警告演出・吸引処理・螺旋吸い込み演出・
リスポーン処理・カメラ揺れ・デバッグUI の技術検証として残す
（吸引・螺旋・水流はゴール演出や場外ギミックとして本線に還流予定）。

## Fall Guys 的な要素（今後の方向性）

- 操作はシンプル（移動＋ジャンプだけ）
- 動きは少しバタバタしていてかわいい（手足をバタつかせて走る）
- 押し合いで事故が起きる（物理まかせ）
- 転ぶ・跳ねる・流されるなどの物理的な面白さ
- 勝敗よりも、見た瞬間に笑える状況が起こることを優先

v0.2.5 では作り込まず、「競技として成立しそうか」の確認まで。

## 便器ゴール型競技の基本ルール

```
長方形の3Dフィールドで、プレイヤーがボールを押し合い、
左右に設置された巨大便器ゴールへボールを流し込む。
ゴールすると水が流れて得点になる。
```

- v0.2.5 は1人用。ボールがどちらの便器に入っても「その便器に流し込んだ数」を数える
- どちらの便器が誰の得点になるか（自陣を守る式か、相手陣に入れる式か）は
  v0.3 のチーム分け設計時に確定する

## 今回実装すること

- 長方形の3Dフィールド（床・壁・センターライン）
- 左右に巨大便器ゴール（グレーボックス。あか/あお で識別）
- 中央にボール（物理で転がる球体）
- プレイヤー1体（移動・ジャンプ・ボールを押せる）
- ボールが便器の開口部を通ると得点
- 得点時の水流演出（渦・水位低下・スプラッシュ・カメラ揺れ・「ゴーーール！」）
- 得点後にボールを中央へ戻す
- スコアUI・イベントログ・R キーでリセット
- ボール場外時の自動復帰（保険）
- 将来の複数人対戦に拡張しやすい構造（入力 `p1_*`、`player_index`、ゴールはシグナル式）

## 今回実装しないこと

オンライン対戦 / ローカル複数人対戦 / アイテムの本実装 / 複数ステージ /
高品質3Dモデル / BGM / Steam連携 / タイトル画面 / 勝敗演出 / 複雑なルール /
大規模リファクタリング / 既存 v0.2 の削除

## 将来アイテム案（v0.2.5 では実装しない設計メモ）

共通方針: アイテムは「フィールドに置かれる物理オブジェクト or 一時効果」とし、
ボール・プレイヤーの実装に密結合させない。
ボールは RigidBody3D なので外力・摩擦変更で干渉でき、
プレイヤーは移動パラメータが `@export` なので速度低下系のデバフを掛けやすい。

### 1. うんこ（フィールド妨害）

- やわらかいうんこ: 床に広がって滑る（床の摩擦を局所的に下げる Area3D）
- ねばねばうんこ: 移動速度やジャンプ力を下げる（プレイヤーの export 値に係数）
- 硬いうんこ: 障害物になりボールを跳ね返す（StaticBody/RigidBody）
- 水流でまとめて動くうんこ: 水流演出時に一斉に流れてカオスを生む

### 2. ブラシ（近接制御・掃除）

- 前方をスイープして相手やボールを押す（プレイヤー前方の Area3D に撃力）
- 床のうんこを除去する（うんこ側が掃除通知を受ける）
- ボールに当てると強めに飛ぶ
- 防御というより、掃除と妨害の中間

### 3. トイレットペーパー（防御・トラップ）

- 壁や柱に巻き付いて水流に耐える（吸引無効化。v0.2 の吸引処理を還流させたとき用）
- 一定時間その場に踏ん張れる
- 床に伸ばして相手の足を取る（通過した相手を減速）
- ボールに巻き付けて動きを遅くする（ボールの damp を一時的に上げる）

## プレイヤーのピクトデザイン方針

一般的なピクトグラム風・記号的デザインを目指す（特定作品の模倣はしない）。

- 丸い頭＋ずんぐりした胴体＋太短い手足
- 顔情報は点目程度に抑える
- 1色（チームカラー想定の単色）で識別
- 遠目でもシルエットが分かる
- 走ると手足がバタバタ揺れてかわいい
- 転ぶ・跳ねる・流される動きが映える

v0.2.5 ではプリミティブ形状（球＋円柱＋カプセル）の仮モデルで、
丸頭・胴体・短い手足・点目＋走行時の手足スイングまでを実装する。

## 操作方法

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動 |
| Space | ジャンプ |
| R | リセット（スコア・ボール・プレイヤー位置） |

カメラはフィールド全体が見える斜め上の固定視点
（プレイヤー・ボール・左右の便器ゴール・水流演出が常に見える）。

- [ ] ゴール時に水流演出（渦・水位低下・スプラッシュ・揺れ・ゴール表示）が出るか

- [ ] あか/あお のゴール識別が分かるか

- [ ] ボールが場外に出ても自動で中央へ戻るか

## v0.3 ローカル2〜4人対戦への拡張方針

- 入力: `p2_*`〜`p4_*` アクションを project.godot に追加（プレイヤーは `p%d_*` を参照済み）
- プレイヤー: `player_index` とチームカラーを変えたインスタンスを追加スポーン
- チーム制: 便器ゴールにチームを割り当て、「相手の便器に入れたら得点」等のルール確定
- 押し合い: CharacterBody3D 同士は自動で押し合わないため、プレイヤー間の
  押し出し処理（衝突時に相互に速度を与える）を実装する ← v0.3 の最重要実装
- カメラ: 全体視点なので複数人でもほぼそのまま使える（必要ならズーム調整のみ)
- UI: スコア表示をチーム別に、ログはそのまま
- その後: うんこ→ブラシ→トイレットペーパーの順にアイテムを1種類ずつ検証
