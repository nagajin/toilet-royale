# Spec: v0.2 3D Graybox Prototype

## v0.2 の目的

「3D空間で、巨大トイレの水流に吸い込まれる挙動が面白いか」を検証する。

- 最終的な方向性は3D物理パーティアクション（「めっちゃカメレオン」系）
- v0.1 の 2D Canvas 版（`prototype/`）は完成版の土台ではなく**参考実装**として保存する
- v0.2 は Godot 4 のグレーボックス（仮形状のみ）で、見た目の完成度は問わない

## v0.2 で実装すること

- Godot 4 の最小3Dプロジェクト（`game/` ディレクトリ、`prototype/` とは独立）
- 巨大トイレを表すグレーボックスステージ1つ
- プレイヤー1体（移動・ジャンプ）
- 三人称・見下ろし気味の追従カメラ
- 中央の便器穴
- 一定時間ごとの水流イベント（通常 → 警告 → 水流 の状態機械）
- 水流前の警告演出（タンク振動・水位上昇・点滅テキスト・カメラ微振動）
- 水流中の吸引（便器穴に近いほど強い。空中では更に強い）
- 便器穴に落ちたら脱落演出（螺旋で吸い込まれる）→ リスポーン
- 外周から落ちても脱落 → リスポーン
- デバッグUI（フェーズ・残り時間・回数・イベントログ・操作説明）

## v0.2 で実装しないこと

オンライン対戦 / Steam連携 / 複数ステージ / 複数キャラクター / アイテム /
高品質3Dモデル / 本格アニメーション / BGM / ランキング / 課金 / セーブ / 複雑なUI

## 3Dステージ構成（グレーボックス）

ステージ全体が「巨大トイレの上」である。プレイヤーは便座リングの上で戦う。

```
            [タンク(箱)]          ← 警告時に振動する
        ____________________
       /   便座リング(円環)   \    ← プレイヤーが立つ足場
      |    外半径13m          |
      |   ┌─ 穴 半径5.5m ─┐   |   ← 中央の便器穴
      |   │   水面(青)     │   |   ← 穴の底に水。水流中は渦(白いスポーク)が回転
       \  └───────────────┘  /
        ‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾
   下方に KillZone（外周からの転落を検出）
```

- 便座リング: CSGCylinder3D（外半径13m・高さ2m）から CSGCylinder3D（半径5.5m）を減算
- タンク: CSGBox3D（12×8×3.5m）。リング後方に接し、壁としても機能する
- 水面: 半透明の青い CylinderMesh。警告中は水位が上がり、水流中は下がる
- 渦: 白い板2枚のクロス。水流中のみ表示して回転
- DrainZone: 穴の内側の Area3D。入ると脱落（螺旋演出）
- OuterKillZone: y=-24 の広い Area3D。外周からの転落を検出

## プレイヤー操作

- WASD / 矢印キーで移動（カメラ固定ヨーなので画面方向と一致）
- Space でジャンプ
- R でリセット（カウンタ・水流サイクル・位置を初期化）
- CharacterBody3D + カプセル。目標速度への補間で移動
  （地上: 補間強、空中: 補間弱 = 空中は吸引に流されやすい）
- 空中ではコロコロ回転する見た目（物理的なバカっぽさ担当）
- 入力アクションは `p1_*` プレフィックス。2〜4人対戦時は `p2_*`… を追加し、
  Player インスタンスの `player_index` を変えるだけで増やせる

## 水流ギミック

2D版（`prototype/sim.js`）で検証した設計の移植（コードの直訳はしない）:

| フェーズ | 時間 | 演出 |
|---|---|---|
| idle | 6.0s | カウントダウン表示のみ |
| warning | 2.5s | タンク振動・水位上昇・「ゴゴゴゴ…」点滅・カメラ微振動 |
| flushing | 3.5s | 吸引・渦回転・水位低下・「水流中！！」・カメラ振動 |

- 吸引は加速度: `SUCTION(26) × 距離係数(0.45〜1.4) × 空中係数(空中1.8倍)`
- 穴に近いほど強く吸われる（距離減衰スケール 14m）
- バランス目標:
  - リング中央付近で無入力 → 1回の水流で吸い込まれる
  - 外周付近で無入力 → ぎりぎり耐えられる
  - 外向きに走れば抵抗できる（操作不能ではない）
  - 水流中にジャンプすると空中係数で一気に持っていかれる（リスクとして意図）
- FlushController は純ロジック。吸引はプレイヤー側が毎物理フレーム
  `get_suction_accel()` を問い合わせる形で、プレイヤー数に依存しない

## 脱落条件

1. 便器穴に落ちる（DrainZone に接触）
   → 螺旋を描いて縮みながら水没する演出（約1.3s）→ 0.9s 後にリスポーン
2. 外周から転落（OuterKillZone に接触）
   → 即リスポーン待ち 0.9s → リスポーン

いずれも「流された回数」としてカウントし、ログに記録する。

## デバッグ確認方法

Godot 4.3+ をインストールした環境で:

```bash
# エディタで開く
godot --path game --editor
# または直接実行
godot --path game
```

確認項目:

- [ ] プレイヤーがWASD/矢印で移動、Spaceでジャンプできる
- [ ] 約6秒後に警告（タンク振動・ゴゴゴゴ点滅・水位上昇）が出る
- [ ] 水流中に便器穴方向へ引っ張られる
- [ ] 外向きに走れば逃げ切れる／立ち止まると吸い込まれる
- [ ] 穴に落ちると螺旋演出→リスポーンする
- [ ] 外周から落ちてもリスポーンする
- [ ] 左上に状態、下部にログが出る。Rでリセットできる
- [ ] 吸い込まれる瞬間をカメラが追い、動画映えするか（人間の主観評価）

## v0.3 への拡張方針

- ローカル2〜4人対戦: `p2_*`〜`p4_*` の入力アクション追加、Player を複数スポーン、
  最後の1人が勝ち残るラウンド制、プレイヤー同士の押し合い（衝突＋押し出し力）
- カメラを「全員が映る固定カメラ」または「全員の中心を追うカメラ」に変更
- 面白さが確認できたら: 効果音（水流・吸い込み）、便器のふた等のギミック検討
